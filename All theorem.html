All Probablity Theorem in Short

1. Normal Probability

A bag contains 3 Red and 2 Blue balls.
One ball is drawn at random.
Find the probability of getting a Red ball.

\[P(Red) = \frac{3}{5}\]

2. Complementary Probability

A bag contains 3 Red and 2 Blue balls.
One ball is drawn at random.
Find the probability of NOT getting a Red ball.

\[P(Red^c) = 1 - \frac{3}{5} = \frac{2}{5}\]

Note:
\(P(Red^c) == P(Blue) = \frac{2}{5}\)

3. Combination Probability

A bag contains 3 Red and 2 Blue balls.
Two balls are drawn together.
Find the probability that both balls are Red.

\[P(both\ Red\ ball) = \frac{{}^3C_2}{{}^5C_3} = \frac{3}{10}\]

4. Addition Theorem

A bag contains 3 Red and 2 Blue balls.
One ball is drawn at random.
Find the probability that the ball is Red OR Blue.

\[P(Red \cup Blue) = \frac{3}{5} + \frac{2}{5} = \frac{5}{5} = 1\]

5. Multiplication Theorem

A bag contains 3 Red and 2 Blue balls.
Two balls are drawn one after another without replacement.
Find the probability that both balls are Red.

\[P(R \cap R) = \frac{3}{5} \times \frac{2}{4} = \frac{6}{20} = \frac{3}{10}\]

6. Conditional Probability

A bag contains 3 Red and 2 Blue balls.
Two balls are drawn one after another without replacement.
If the first ball is Red, find the probability that the second ball is also Red.

\[P(B|A) = \frac{P(A \cap B)}{P(A)}\]
\[P(R_2| R_1) = \frac{P(R \cap R)}{P(R)} = \frac{\frac{3}{10}}{\frac{3}{5}} = \frac{3}{10} \times \frac{5}{3} = \frac{1}{2}\]

7. Bayes’ Theorem

Bag A contains 3 Red and 2 Blue balls.
Bag B contains 1 Red and 4 Blue balls.

One bag is chosen at random and one ball is drawn.
If the ball drawn is Red, find the probability that it came from Bag A.

\[P(A|R) = \frac{P(A)P(R|A)}{P(A)P(R|A) + P(B)P(B|R)}\]
\[P(A|R) = \frac{\frac{1}{2} \times \frac{3}{5}}{\left( \frac{1}{2} \times \frac{3}{5} \right) + \left( \frac{1}{2} \times \frac{1}{5}\right)}\]
\[P(A|R) = \frac{\frac{3}{10}}{\frac{4}{10}} = \frac{3}{4}\]

8. Bernoulli’s Theorem

A bag contains 3 Red and 2 Blue balls.
A ball is drawn 3 times with replacement.
Find the probability of getting exactly 2 Red balls.

\[P(2\ Red) = {}^3C_2 \times \left( \frac{3}{5}\right)^2 \times \left( 1 - \frac{3}{5} \right)^{3-2}\]
\[P(2\ Red) = 3 \times \frac{3}{5} \times \frac{3}{5} \times \frac{2}{5}\]
\[P(2\ Red) = \frac{54}{124}\]
