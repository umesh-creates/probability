Cumulative Distribution Function - CDF

Probablity Mass Functionn (Discrete value)

"किसी मान तक की कुल (जमा हुई) probability"

\[F(x) = P(X ≤ x)\]

अर्थात् x से छोटी या x के बराबर सभी values की probabilities का योग।

Example

मान लो किसी Random Variable X की Probability Distribution यह है:

X P(X)
0 0.2
1 0.3
2 0.4
3 0.1

Probability का कुल योग:

0.2 + 0.3 + 0.4 + 0.1 = 1 ✔

CDF कैसे निकालते हैं?

\[0 + 1 + (01+2) + (012 + 3) = CDF\]
\[F(0) = 0.2\]
\[F(1) = F(0) + F(1) = 0.5\]
\[F(2) = F(1) + F(2) = 0.9\]
\[F(3) = F(2) + F(3) = 1.0\]

इसका अर्थ क्या है?

\(F(1) = 0.5\)

इसका अर्थ:

X का मान 1 या उससे कम आने की probability 0.5 है।

\(F(2) = 0.9\)

इसका अर्थ:

X का मान 2 या उससे कम आने की probability 0.9 है।
